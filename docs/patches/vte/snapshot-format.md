# Snapshot Format

This page describes the **logical state** captured by a snapshot. The physical
encoding is an opaque binary blob produced by VTE; treat it as a versioned
container, not as something to parse yourself.

## Container

- **Magic** `0x56534E50` (`"VSNP"`)
- **Version** `3`
- Format readers reject unknown magic/version up front.

## What is serialized

```text
Header            magic, version, rows, cols, scrollback-limit,
                  cursor shape, active screen flag
Modes             ECMA mode bitmask, private-mode bitmask
Palette           256 palette entries × 2 sources (set flag + RGB)
Capabilities      bidi, allow-hyperlink, mouse-tracking mode,
                  ambiguous-width mode
Terminal defaults default cell, default colors, character-replacement
                  table + active index
Scrolling region  restricted flag + top/bottom/left/right (DECSTBM/DECSLRM)
Tab stops         one bit per column
Screen (normal)   cursor block, saved-cursor block, full ring rows
Screen (alternate) cursor block, saved-cursor block, full ring rows
```

### Ring rows

Each screen ring is stored as rows over `[ring delta, ring next)`:

```text
row = length, soft_wrapped, bidi_flags, cells…
cell = character, attribute mask, color mask, optional hyperlink URL
```

Frozen rows are deep-copied before serialization; hyperlink URLs are resolved
through the ring so they survive independently of the active index.

## What is deliberately NOT serialized

- **Streams / line-buffering state** — regenerated by VTE after restore.
- **Pending input / PTY traffic** — application-level, never part of terminal
  state.
- **Scrollbar widget state** — a view concern, not terminal state.
- **`cwd`, file-URI, title** (future format work).

## Ground truth

The same snapshot bytes are what Remin stores in the database (as a BLOB), and
is mirrored base64-inline in the JSON workspace file. The byte image is the
single source of truth for a terminal's restored state.

Changing the snapshot byte format must bump `SNAPSHOT_VERSION` and update
[testing.md](testing.md) round-trip expectations.
